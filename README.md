# .paradise-nursery
Paradise Nursery
Paradise Nursery is an online plant shopping application
built using React and Redux Toolkit.
Features
Browse six houseplants in three categories.
View plant images, names, and prices.
Add plants to the shopping cart.
Increase or decrease item quantities.
Remove plants from the cart.
Calculate the total number of plants and total cost.
Navigate between Home, Plants, and Cart pages.
Technologies
React
Redux Toolkit
JavaScript
CSS
Vite
